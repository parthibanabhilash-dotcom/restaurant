# EatNow — Modern & Responsive Restaurant Website

**EatNow** is a modern, high-performance, responsive restaurant and food delivery web application built with **React**, **Vite**, **Tailwind CSS**, and **Lucide Icons**.

## 🚀 Features

- **Dynamic Homepage**:
  - **Sticky Navbar**: Brand logo with animated badge, smooth section navigation links, table reservation trigger, mobile responsive drawer, and cart toggle with real-time item count badge.
  - **Hero Section**: High-impact culinary presentation, appetizing headlines, dual CTAs ("Order Food Now", "Reserve a Table"), and floating live metrics (4.9 Rating, 25-Min Delivery, 100% Organic).
  - **Special Deals Banner**: One-click apply & copy for promo code `EATNOW20` (20% off).
  - **Interactive Food Menu**:
    - Filter by 8 categories (All Dishes, Burgers, Artisanal Pizzas, Asian Bowls, Handcrafted Pastas, Farm Salads, Desserts, Artisan Beverages).
    - Real-time search by dish title, ingredient, or description.
    - Dietary filters: All, 🌱 Vegetarian, 🥩 Non-Veg, 🌶️ Spicy, ⭐ Chef's Special.
    - Sorting by Featured, Rating (highest first), Price (low to high, high to low).
  - **Dish Cards & Quick View Modal**:
    - HD imagery with hover zoom and status badges.
    - Detail modal for selecting spice levels (Mild, Medium, Spicy), add-ons (extra melted cheese), and kitchen notes.
  - **Why Choose EatNow (Features Grid)**:
    - 30-min express delivery, 100% organic local produce, Michelin-trained chefs, eco-friendly compostable packaging.
    - Key metrics counter.
  - **Customer Reviews & Testimonials**:
    - Verified diner reviews, 5-star ratings, dish recommendation tags, and reviewer avatars.
  - **Table Reservation Modal**:
    - Name, phone, email, date, time slots, guest counter, dining occasions, and interactive booking reference generation.
  - **Shopping Cart Drawer**:
    - Slide-over panel with item thumbnails, customizable notes, and quantity controls (`+` / `-` / delete).
    - Dynamic Free Delivery Progress Bar (unlocks free delivery over $40).
    - Promo code engine (`EATNOW20`, `TASTY10`, `FREESHIP`).
    - Subtotal, delivery fee, tax, discount, and total computation.
  - **Express Checkout UI**:
    - Order type switcher (Express Delivery vs Restaurant Pickup).
    - Customer contact and delivery address with suite/apt and delivery instructions.
    - Courier / Kitchen tip selection ($2, $3.50, $5, No tip).
    - Payment method switcher (Credit Card, Apple Pay / Google Pay, Cash on Delivery).
    - 256-bit secure checkout button with confetti celebration explosion.
  - **Live Order Tracker**:
    - Real-time order status stepper: Order Confirmed ➔ Kitchen Crafting ➔ Out for Delivery ➔ Bon Appétit!
    - Countdown timer, itemized receipt breakdown, and printable order summary.
  - **Toast Alerts**:
    - Real-time feedback for cart updates, coupon redemptions, reservations, and errors.
  - **Footer**:
    - Brand manifesto, opening hours, address & contact, interactive newsletter signup, and social links.

## 🛠️ Tech Stack

- **React 18**
- **Vite 5**
- **Tailwind CSS 3**
- **Lucide React** (modern iconography)
- **Canvas-Confetti** (order celebration)

## 🏃 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
